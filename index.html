👋 About Me

I am a Research Engineer in the Parasitology department at Institut Pasteur in Paris, where I have been for the past two years. My work sits between biology and software: I build tools that help scientists analyse sequencing data without having to fight their computing environment.

Before that, I led the dry lab of the Biomics sequencing platform at Institut Pasteur. Running a platform means analysing many projects with the same care, again and again. That experience shaped how I think about software, and it is the reason I started Damona, a tool for managing and sharing reproducible software environments. Earlier still, I spent five years at the European Bioinformatics Institute (EBI) in Cambridge. My academic training is in physics, with a PhD, and I still approach data problems with that mindset.

I am the principal developer of several open-source projects: Sequana, a collection of Snakemake pipelines for NGS analysis, Bioservices, for accessing biological web services from Python, Damona, and Bioconvert, for converting between bioinformatics file formats. What connects them is reproducibility: an analysis should give the same result next month, on another machine, in someone else's hands.

📄 Publications

Intrinsic differences in hamster and mouse macrophage biology correlate with susceptibility to Leishmania donovani infection

Journal of Leukocyte Biology, 2026

Compares bone marrow-derived macrophages from susceptible hamsters and resistant mice to identify intrinsic cellular features behind differential susceptibility to Leishmania donovani. Provides a validated protocol for generating hamster macrophages and a comparative transcriptomic analysis highlighting rodent-specific metabolic and immune pathways.

LORA: a polymorphic multi-sample long read assembly pipeline

NAR Genomics and Bioinformatics, 2026

Presents LORA, a reproducible Snakemake pipeline that assembles genomes from long-read (PacBio and Nanopore) data using several assemblers, including Canu, HiFiasm, Flye and Unicycler. Adds quality assessment, interactive HTML reports, BLAST-based taxonomic identification and completeness evaluation. Distributed as part of the Sequana project.

Reprohackathons: promoting reproducibility in bioinformatics through training

Bioinformatics, 2023

Presents the Reprohackathon, a Master's course running at Université Paris-Saclay for three years with 123 students, combining lessons on reproducibility tools (versioning, containers, workflow systems) with a 3–4 month hands-on data-reanalysis project. Shows that in-depth teaching of reproducibility concepts and tools significantly improves students' understanding and abilities.

BioConvert: a comprehensive format converter for life sciences

NAR Genomics and Bioinformatics, 2023

Introduces BioConvert, a collaborative tool that facilitates the interconversion of life science data between hundreds of file formats. Provides a unified command-line and Python interface to reduce format-conversion friction in bioinformatics pipelines.

Sequana Coverage: Detection of Genomic Variations with a DNA Coverage Analysis Tool

GigaScience, 2018

Presents a standalone tool for analysing DNA coverage data from sequencing experiments. The method detects low and high coverage regions, identifies outliers, and generates HTML reports for quality control.

Sequana: a set of Snakemake NGS pipelines

Journal of Open Source Software, 2017

Introduces the Sequana framework providing a collection of modular, reproducible NGS pipelines built on Snakemake. Covers RNA-seq, variant calling, quality control, and de-novo assembly workflows.

BioServices: a common Python package to access biological web services

Bioinformatics, 2013

Describes BioServices, a Python package providing a unified interface to many biological databases and web services. Removes the need to manage heterogeneous APIs and simplifies bioinformatics scripting workflows.

Training Signalling Pathway Maps to Biochemical Data with Constrained Fuzzy Logic

PLOS Computational Biology, 2012

Introduces a constrained fuzzy logic formalism to model signal transduction networks, enabling inference of pathway activity from phosphoproteomic data. Implemented in the open-source CellNOpt toolbox.

CellNOptR: a flexible toolkit to train protein signalling networks to data using multiple logic formalisms

PLOS ONE, 2012

Presents CellNOptR, an R package for training Boolean and fuzzy logic models of signalling networks to phosphoproteomic data. Supports multiple logic formalisms and integrates with the broader CellNOpt toolbox ecosystem.

CNOFuzzy: a flexible toolkit to train fuzzy logic models to data

Bioinformatics, 2010

Describes the CNOFuzzy toolbox for training fuzzy logic models of signal transduction to experimental data, extending Boolean modelling to handle graded biological responses and continuous measurements.

CellNOpt: using signalling pathway models to predict dynamic drug-combination effects

BMC Systems Biology, 2009

Introduces the CellNOpt framework for training prior knowledge signalling network models to experimental data, enabling prediction of drug-combination effects and identification of network rewiring in disease contexts.
